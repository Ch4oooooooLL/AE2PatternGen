# v1.7

## 更新摘要

- 新增“配方浏览器”物品：右键打开后按 `配方池（配方表） -> 规则组 -> 配方明细` 三层浏览服务端配方缓存。
- 规则组按 `(编程电路, NC 不消耗物品)` 唯一确定，组内所有配方的编程电路与 NC 物品完全一致；规则组默认按配方数量降序，数量相同时按电路编号升序。
- 只有 1 条配方的规则组与“无电路且无 NC”的通用配方默认折叠，界面底部提供开关展开，顶部会注明折叠数量。
- 每组支持一键生成全部样板，也可展开后单条生成；第三层“预览与过滤”页展示输入/输出清单，并支持与样板生成器相同的 5 个显式过滤字段（`[id]` / `(矿辞)` / `{名字}`）与电压档位。
- 新增按来源分通道的浏览器仓储：配方浏览器生成的样板写入独立通道，与样板生成器的默认通道互不阻塞；蹲下右键空气可查看、删除或清空。
- 新增投递功能：右键 GT 样板输入总成/总线（GT5U `MTEHatchCraftingInputME`、GTNL 超级总成）或 AE2 面板接口即可投递，并同时：
  - 将目标重命名为 `<池名>_<电路>_NC_<NC物品…>`；
  - 把该规则的编程电路写入目标电路槽（规则不要求电路时清空电路槽）；
  - 把该规则的 NC 物品加入 NEI 书签，便于拖入总成手动槽。
  - 样板槽范围严格取 `[0, 电路槽)`，不会污染电路槽、手动槽与内部槽。
- 配方浏览与规则分组数据均由服务端配方缓存派生，缓存重建或清空后会自动失效重算，无需手动清理。
- 同时包含 GTNH 290Beta3 依赖适配：GT5-Unofficial `5.09.54.133`、AE2-Unofficial `rv3-beta-1050-GTNH`、NEI `2.8.130-GTNH`、AE2FluidCraft-Rework `1.5.106-gtnh`、GTNHLib `0.11.46`、ModularUI2 `2.3.88`、ModularUI `1.3.4`。
- 如果你发现任何 bug，请到 GitHub Issues 提交反馈。
